# 3D 列印快速估價網站

## 已實作
- 繁體中文、手機友善的客戶前台，STL/3MF 上傳、機型、數量、顏色、用途、備註。
- Flask 後端可呼叫 Bambu Studio CLI 實際切片（需自行配置 Bambu Studio 執行檔與六個完整切片設定檔）。
- 報價：每件耗材重量 g × NT$1 + 列印分鐘 × NT$0.5；乘上數量。無低消、無開機費。
- **總耗材克數嚴格大於 350 g** 時，顯示總價 20% 預收款，首次列印成功後退回（退款由店家人工處理）。
- 自動切片若失敗或無法解析回傳資料，提示人工詢價，不使用臆測數據。
- 色系參考使用者提供的深藍黑＋薄荷綠。

## 安裝
1. Python 3.10+，執行 `pip install -r requirements.txt`。
2. 確認 Bambu Studio CLI 能在電腦/伺服器運作（官方說明 https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage）。
3. 在 `profiles/` 放入六個 **完整且已經驗證** 的 JSON，命名方式參考該資料夾 README。
4. 設定環境變數 `BAMBU_STUDIO_CLI` 為 Bambu Studio 可執行檔的**絕對路徑**。
5. 執行 `python app.py`；在 http://127.0.0.1:5000 瀏覽。正式對外需部署至有 Bambu Studio CLI 的伺服器，配置 HTTPS、反向代理、隔離執行身分及作業佇列。

## 使用者需知道的限制
- 目前交付的是**可啟動的專案與整合骨架**，沒有隨附拓竹切片引擎，也沒有預先產出經驗證的機型設定檔。因此新安裝環境在未配置前會明確回傳 503。
- 部分拓竹版本輸出 3MF 的 G-code 註解格式不同，`read_result` 解析規則可能要按實際輸出調整。
- 尚未提供真正的列印尺寸驗證；最終需要根據切片返回的板面/超界資訊確認尺寸可列印。
- 多盤、多色、模型拆件、縮放、修改 3MF 外部設定、支撐材料、料盤用量和特殊費用，需要更多實際檔案測試。
- 當前只支援一個模型檔案；數量是根據每件估算線性乘上，不會把全部複製排到板上重算時間。
- 本系統不會下單、收款或連接印表機送印；所有價格是初步參考。
- 若要公開提供不受信任的模型檔上傳，**必須**在 Docker/VM 沙箱中隔離切片服務、配置資源限制、排隊與速率限制；不要直接將內建開發伺服器暴露到網路。
